## Описание

Пользовательский интерфейс для отправки и получения сообщений в Telegram

## Запуск

### Требования

- Node.js 20+
- npm

### Установка

```bash
npm install
```

### Настройка

Создайте файл `.env` в корне проекта:

```env
VITE_GREEN_API_BASE_URL=<url инстанса greenapi>
```

### Запуск в режиме разработки

```bash
npm run dev
```

Проект будет доступен по адресу:

```text
http://localhost:5173
```

После запуска откройте адрес, указанный Vite в консоли.

### Сборка

```bash
npm run build
```

### Проверка форматирования и линтинга

```bash
npm run format:check
npm run lint
```
